ภาพรวม ค้นหาสินค้า สร้างคลิปเดี่ยว สร้างแบบ Batch หลายแนวพร้อมกัน ตัวละคร ลายน้ำ แคปชั่น+ลิงก์ คลังคลิป ดาวน์โหลด+Shopee Pack รายงานผลงาน ประวัติ ตั้งค่า API แก้ปัญหาที่พบบ่อย

🗺 ภาพรวมลำดับการทำงาน

1. หาสินค้า→ 2. สร้างคลิป→ 3. แคปชั่น→ 4. ดาวน์โหลด/Shopee Pack→ 5. อัปขึ้น Shopee/TikTok

ใช้เมนูซ้ายไล่ตามลำดับนี้ได้เลย แต่ละหน้าเชื่อมข้อมูลกันอัตโนมัติ (ใส่ครั้งเดียว ใช้ได้ทุกที่)

🔍 ค้นหาสินค้า

เมนูบนสุดซ้าย "🔍 ค้นหาสินค้า (Shoptool)" เปิดเว็บ shoptool.app ในแท็บใหม่ (ใช้บัญชี/license ของคุณเอง) สำหรับหาสินค้าที่กำลังขายดี/มีค่าคอมสูงมาทำคลิปต่อ

เจอสินค้าที่สนใจแล้ว กลับมาที่แท็บนี้ กด "สร้างคลิป" แล้วกรอกข้อมูลตามปกติ (ยังไม่มีการส่งข้อมูลข้ามระบบอัตโนมัติ)

✏️ สร้างคลิปเดี่ยว

  1. อัปโหลด รูปสินค้า — ต้องเป็นรูปสินค้าล้วนๆ พื้นหลังเรียบ ห้ามใช้รูปจากหน้า listing ที่มีแบนเนอร์โลโก้ ตรา "No.1" แถบไอคอนฟีเจอร์ หรือป้ายลดราคาปนอยู่ ต้องครอปกราฟิกพวกนี้ออกก่อนเสมอ ไม่งั้น AI จะวาดสินค้าไม่ตรงปก
  2. ใส่ ลิงก์สินค้า (Shopee/TikTok Shop/Lazada) — บังคับ กดสร้างคลิปไม่ได้ถ้ายังไม่ใส่ ใช้ปักตะกร้า+แนบแคปชั่นอัตโนมัติ
  3. ตั้ง ชื่อสินค้า — ระบบเลือกตัวละครพรีเซนเตอร์ให้อัตโนมัติตามหมวดสินค้าที่พิมพ์ + ให้ AI แต่งคำโฆษณา (hook/feature/CTA) ให้ตรงสินค้าถ้าไม่กรอกเอง
  4. เลือก แนวคลิป (genre) อย่างน้อย 1 แนว
  5. กด สร้างคลิปโฆษณา → รอสักครู่ (สินค้าใหม่ AI แต่งคำใช้เวลา ~5-15 วิ ปุ่มจะขึ้น "กำลังแต่งคำโฆษณา...") → ระบบโชว์พรอมต์ที่แต่งให้ก่อน (ยังไม่หักเครดิต)
  6. ตรวจพรอมต์แล้วกด ยืนยันสร้างจริง — ตอนนี้หักเครดิตแล้ว
  7. สร้างครบ 3 segment (A+B+C) ระบบจะต่อเป็นคลิปเดียวให้อัตโนมัติหลังสร้างเสร็จ

📦 สร้างแบบ Batch (หลายสินค้าในรอบเดียว)

  1. ไปหน้า "สร้างแบบ Batch" → ดาวน์โหลด Template CSV
  2. กรอกข้อมูลสินค้าแต่ละแถว (แถวละ 1 สินค้า) สูงสุด 30 สินค้าต่อรอบ
  3. ตั้งชื่อไฟล์รูปให้ตรงกับคอลัมน์ reference_image_filename แล้วอัปโหลดรูปทั้งหมดพร้อมกัน
  4. กด Preview (ฟรี ไม่หักเครดิต) → ตรวจจำนวนสินค้า/คลิปที่จะสร้าง
  5. กด ยืนยันสร้างจริงทั้งหมด — สินค้าใหม่หลายชิ้นอาจใช้เวลาสร้างพรอมต์หลายสิบวินาที (AI แต่งคำให้ทีละสินค้า)

🎬 สร้างหลายแนวคลิปพร้อมกัน (ไม่บังคับ)

ทั้งหน้าสร้างเดี่ยว (ติ๊กเลือกได้หลายแนว) และ Batch CSV (คอลัมน์ genres คั่นด้วยจุลภาค) รองรับการสร้างหลายสไตล์จากสินค้าเดียวกันในรอบเดียว เหมาะกับการทดสอบว่าแนวไหนขายดีกว่า

ผลลัพธ์: 2 แนว × 3 segment = 6 คลิป (หักเครดิตตามจำนวนนี้)
หักเครดิตเพิ่มตามจำนวนแนวที่เลือกจริง — เช็คตัวเลขที่ระบบโชว์ก่อนกดยืนยันเสมอ

🎭 ตัวละคร (พรีเซนเตอร์)

ระบบมีตัวละครสำเร็จรูปให้เลือกในหน้าสร้างคลิป แต่ละคนออกแบบให้เหมาะกับสินค้าคนละแบบ พิมพ์ชื่อสินค้าแล้วออกจากช่อง ระบบจะเลือกให้อัตโนมัติตามหมวดสินค้า — ยังเปลี่ยนเองได้เสมอ

🔖 ลายน้ำ / โลโก้กันก๊อบปี้

ใส่ข้อความหรืออัปโหลดโลโก้ในส่วน "ปรับแต่งเพิ่มเติม" เลือกตำแหน่งและความโปร่งใสได้ ระบบจะเบิร์นทับคลิปทุก segment ให้อัตโนมัติหลังสร้างเสร็จ (ไม่ต้องทำเอง)

📝 แคปชั่น + แฮชแท็ก + ลิงก์สินค้า

หลังกรอกข้อมูลสินค้า เลื่อนลงไปที่ส่วน "แคปชั่น + แฮชแท็ก" เลือกแพลตฟอร์ม (TikTok/Facebook/Shopee) แล้วกดสร้าง — ถ้าใส่ลิงก์สินค้าไว้ จะแนบต่อท้ายให้อัตโนมัติทุกแคปชั่น พร้อมคัดลอกไปโพสต์/ปักตะกร้าได้เลย

🗂 คลังคลิปทั้งหมด

ดูคลิปทั้งหมดที่เคยสร้าง แยกแท็บตามสินค้า เล่นดูได้ในหน้าเว็บโดยตรง

⬇️ จัดการไฟล์ดาวน์โหลด + Shopee Pack

ดูขนาดไฟล์แต่ละคลิป + พื้นที่ใช้ทั้งหมด, ดาวน์โหลดไฟล์ลงเครื่อง, หรือลบไฟล์ที่ไม่ใช้แล้ว

  • เลือกทั้งหมด/บางส่วน + ดาวน์โหลดเป็น ZIP — รวมหลายคลิปเป็นไฟล์เดียวโหลดทีเดียว
  • 🛒 Shopee Pack — จับคู่ไฟล์วิดีโอกับข้อมูลสินค้า+แคปชั่นเป็นไฟล์ .json ชื่อเดียวกันกับวิดีโอ พร้อมอัปโหลดขึ้นเครื่องมือ Shopee bulk upload ได้เลย

การลบไฟล์เป็นการลบถาวร กู้คืนไม่ได้ และไฟล์จะถูกลบอัตโนมัติเมื่อเก่าเกินกำหนด (ดูข้อความแจ้งเตือนในหน้านี้) — ดาวน์โหลดเก็บไว้ก่อนถ้ายังต้องใช้

📊 รายงานผลงาน

สรุปเครดิตคงเหลือ, จำนวนคลิปทั้งหมด, เวลาเฉลี่ยต่อคลิป, ความยาวรวม, อัตราความสำเร็จของงานที่ส่งไปสร้าง แยกตามสินค้าและตามวัน

📜 ประวัติการทำงาน

บันทึกทุกครั้งที่ preview / สั่งสร้างคลิป / งานเสร็จ-ล้มเหลว / ต่อคลิป — ใช้ตรวจสอบย้อนหลังได้ว่าเกิดอะไรขึ้นบ้าง

⚙️ ตั้งค่า API

ใส่ USEAPI_TOKEN ของตัวเอง (จาก useapi.net) และอีเมล Google Flow ที่เชื่อมไว้ — ข้อมูลถูกเข้ารหัสก่อนบันทึก เห็นได้เฉพาะบัญชีของคุณเท่านั้น ไม่ปนกับผู้ใช้คนอื่น

ไม่มี USEAPI_TOKEN จะสร้างคลิปจริงไม่ได้ (Preview ยังใช้ได้ปกติเพราะไม่เสียเครดิต)

❓ แก้ปัญหาที่พบบ่อย

  • สินค้าในคลิปหน้าตาเพี้ยน ไม่ตรงปก — ตรวจรูปที่อัปโหลดว่ามีแบนเนอร์/ตรา/ไอคอนปนอยู่ไหม (ดูหัวข้อ "สร้างคลิปเดี่ยว" ด้านบน) ครอปให้เหลือสินค้าล้วนๆ แล้วลองใหม่
  • กดปุ่มแล้วดูเหมือนค้าง ไม่มีอะไรเกิดขึ้น — ระบบกำลังทำงานอยู่เบื้องหลัง (โดยเฉพาะสินค้าใหม่ที่ต้องให้ AI แต่งคำ) ปุ่มจะขึ้นข้อความ "กำลัง..." ระหว่างรอ ปกติไม่เกิน 15-30 วินาที
  • คลิปเก่าหายไปจากคลัง — คลิปที่เก็บไว้นานเกินกำหนดจะถูกลบอัตโนมัติ (ดูจำนวนวันที่หน้าจัดการไฟล์ดาวน์โหลด) ดาวน์โหลดเก็บไว้ก่อนถ้ายังต้องใช้
  • เครดิตในหัวเว็บโชว์ว่างเปล่า — จะกลับมาโชว์เองหลังสร้าง/เช็คสถานะคลิปครั้งถัดไป
