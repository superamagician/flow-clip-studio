✏️ สร้างคลิป

  1. อัปโหลด รูปสินค้า — ต้องเป็นรูปสินค้าล้วนๆ พื้นหลังเรียบ ห้ามใช้รูปจากหน้า listing ที่มีแบนเนอร์โลโก้ ตรา "No.1" แถบไอคอนฟีเจอร์ หรือป้ายลดราคาปนอยู่ (พบมาแล้วว่าทำให้ AI สับสนและวาดสินค้าไม่ตรงปก) ต้องครอปกราฟิกพวกนี้ออกก่อนเสมอ
  2. ตั้ง ชื่อสินค้า — ระบบจะเลือกตัวละครพรีเซนเตอร์ให้อัตโนมัติตามหมวดสินค้าที่พิมพ์
  3. เลือก แนวคลิป (genre): hook_feature_cta (สไตล์ทั่วไป มีคนพูด), asmr (ไม่มีคนพูด เน้นเสียง/สัมผัส), pov (มุมมองคนดูเอง), minimal (เรียบหรู) — ติ๊กเลือกได้มากกว่า 1 แนวพร้อมกัน ระบบจะสร้างครบทุกแนวที่เลือกจากสินค้าเดียวกัน (หักเครดิตเพิ่มตามจำนวนแนวที่เลือก)
  4. กด สร้างคลิปโฆษณา → ระบบจะโชว์พรอมต์ที่แต่งให้ก่อน (ยังไม่หักเครดิต) ตรวจดูแล้วกด ยืนยันสร้างจริง
  5. ถ้าเลือกสร้างครบ 3 segment (A+B+C) ระบบจะต่อเป็นคลิปเดียว 30 วิให้อัตโนมัติหลังสร้างเสร็จ
เปิด "ปรับแต่งเพิ่มเติม" เพื่อกรอก hook/feature/CTA เอง, เลือกตัวละครจากคลัง, ใส่ลายน้ำ/โลโก้กันก๊อบปี้

🎭 ตัวละคร (พรีเซนเตอร์)

ระบบมีตัวละครสำเร็จรูป 6 คน (คลิกเลือกได้ในหน้าสร้างคลิป) แต่ละคนออกแบบให้เหมาะกับสินค้าคนละแบบ พิมพ์ชื่อสินค้าแล้วออกจากช่อง ระบบจะเลือกให้อัตโนมัติ — ยังเปลี่ยนเองได้เสมอ

🔖 ลายน้ำ / โลโก้กันก๊อบปี้

ใส่ข้อความหรืออัปโหลดโลโก้ในส่วน "ปรับแต่งเพิ่มเติม" เลือกตำแหน่งและความโปร่งใสได้ ระบบจะเบิร์นทับคลิปทุก segment ให้อัตโนมัติหลังสร้างเสร็จ (ไม่ต้องทำเอง)

📝 แคปชั่น + แฮชแท็ก

หลังกรอกข้อมูลสินค้าในหน้าสร้างคลิป เลื่อนลงไปที่ส่วน "แคปชั่น + แฮชแท็ก" เลือกแพลตฟอร์ม (TikTok/Facebook/Shopee) แล้วกดสร้าง — ได้ข้อความพร้อมคัดลอกไปโพสต์ทันที

🗂 คลังคลิปทั้งหมด

ดูคลิปทั้งหมดที่เคยสร้าง แยกแท็บตามสินค้า เล่นดูได้ในหน้าเว็บโดยตรง

⬇️ จัดการไฟล์ดาวน์โหลด

ดูขนาดไฟล์แต่ละคลิป + พื้นที่ใช้ทั้งหมด, ดาวน์โหลดไฟล์ลงเครื่อง, หรือลบไฟล์ที่ไม่ใช้แล้วเพื่อประหยัดพื้นที่

การลบไฟล์เป็นการลบถาวร กู้คืนไม่ได้

📊 รายงานผลงาน

สรุปจำนวนคลิป, ความยาวรวม, อัตราความสำเร็จของงานที่ส่งไปสร้าง, แยกตามสินค้าและตามวัน

📜 ประวัติการทำงาน

บันทึกทุกครั้งที่ preview / สั่งสร้างคลิป / งานเสร็จ-ล้มเหลว / ต่อคลิป — ใช้ตรวจสอบย้อนหลังได้ว่าเกิดอะไรขึ้นบ้าง

⚙️ ตั้งค่า API

ใส่ USEAPI_TOKEN ของตัวเอง (จาก useapi.net) และอีเมล Google Flow ที่เชื่อมไว้ — ข้อมูลถูกเข้ารหัสก่อนบันทึก เห็นได้เฉพาะบัญชีของคุณเท่านั้น ไม่ปนกับผู้ใช้คนอื่น

ไม่มี USEAPI_TOKEN จะสร้างคลิปจริงไม่ได้ (Preview ยังใช้ได้ปกติเพราะไม่เสียเครดิต)
